# stampbeam

Stamp filesystem beam paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/stampbeam/

## Install / run

```bash
git clone https://github.com/theworker02/stampbeam.git
cd stampbeam
node src/cli.js
node --test
```
